# Returns Policy

We accept returns of unopened items in their original packaging within
14 days of delivery.

Opened items cannot be returned unless they are defective.

To return an item, contact customer support for a return authorization
number. Write the number on the outside of the package. The customer is
responsible for return shipping costs, and we recommend using a tracked
service.

Returns without an authorization number may be refused.
